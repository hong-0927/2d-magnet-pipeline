# La2CuO4 单层 Heisenberg 哈密顿量

> 本卡片由 `write_hamiltonian.py` 从 Monte Carlo 模型 JSON 生成，全部数值源自模型文件，无额外假设。

## 符号式哈密顿量

```text
H = - J1 · Σ_{⟨ij⟩} S_i·S_j
      - J2 · Σ_{⟨⟨ij⟩⟩} S_i·S_j
      - J3 · Σ_{⟨⟨⟨ij⟩⟩⟩} S_i·S_j
```

## 模型参数

| 项 | 值 |
|---|---|
| 磁性元素 | Cu |
| 自旋 S / S² | 0.5 / 0.25 |
| 维度 | 2D |
| 易轴 | z |
| MAE (meV/离子) | 0 |
| J1 (meV) | -111.8 |
| J2 (meV) | 11.4 |
| J3 (meV) | -2 |

符号约定: `H = -J Σ S·S`，**J > 0 = 铁磁，J < 0 = 反铁磁**。

## 引擎 ↔ 物理约定

- 经典 Heisenberg，单位自旋 |S|=1；交换张量 `J_mat = -(J·S²)·I₃`（把量子自旋尺度吸收进耦合）。
- 单离子各向异性 `A_zz = -MAE`（易轴 z，MAE>0 时 (S^z)² 被压低、有利于自旋沿 z）。
